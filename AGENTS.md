# Anomalica digests

Parent Product and root Core instructions are loaded through `opencode.json` and remain
mandatory. This repository holds extracted digest data and variants consumed by the
assimilator. Read the public digest-format contract in `../anomalica/architecture/` and
the producing `../digester/` code before editing a record. Preserve canonical versus
variant provenance; fix systemic errors in the producer and regenerate rather than
silently hand-correcting output.
